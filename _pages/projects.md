## GenAI MCP Server | Dec 2025 – Present
Developed a specialized Model Context Protocol (MCP) server that provides a secure harness and toolkit for AI agents, allowing LLMs to perform cybersecurity operations within an isolated, containerized environment using Podman.

<u>Highlights</u>:
- Designed a specialized cyber MCP server providing an agentic harness for LLMs to perform security operations in an isolated environment
- Implemented Podman integration to create secure, ephemeral sandboxes for executing cybersecurity tasks safely
- Developed custom tools enabling LLMs to interact with and analyze secure infrastructure, threat feeds, and vulnerability management systems

<u>Tools Used</u>: Python, Podman, Model Context Protocol (MCP), LLMs
